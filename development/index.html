MSX クロス開発の近代化 — 現代の MSX ソフトウェア開発は、実機上のインタープリタ環境から、Linux/macOS/Windows ホスト上での高速なクロスコンパイル環境へと完全に移行しました。中核となる SDCC による高度なレジスタ渡し規約と、Pasmo による確定的アセンブリを組み合わせることで、32 KiB フラット ROM、MegaROM、および MSX-DOS .COM バイナリを瞬時に生成・検証できます。 "Modern MSX development leverages host-side cross-compilation toolchains. 01

SDCC (Small Device C Compiler)

C99 / C89 Optimizing Compiler

Z80 ターゲット向け最適化コード生成。__sdcccall(1) によるレジスタ引数渡し、不要な標準ライブラリの排除（--no-std-crt0）、およびインラインアセンブラによる VDP 最速制御。

SDCC 詳解とビルド規約 →
02

Pasmo

Multi-Platform Z80 Assembler

固定アドレス割り付けアセンブラ。ROM カートリッジ（--bin）、MSX-DOS（.com）、および BLOAD（--msx）形式を単一コマンドで出力し、デバッガシンボルを生成。
