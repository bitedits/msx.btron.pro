SDCC (Compiler)

Small Device C Compiler による MSX 向け最適化 C99 コード生成、呼出規約、およびカートリッジヘッダ統合。 "Definitive technical guide to compiling ANSI C99 code for the Zilog Z80 on MSX platforms using SDCC, covering calling conventions, custom CRT initialization, and memory mapping."
← 開発目録へ戻る (Development Index)
SDCC MSX 開発の基本指針 — 組み込み Z80 向けの SDCC は、PC 向けの汎用コンパイラとは異なり、ホストの標準ライブラリ（stdio, malloc 等）を前提としません。標準の crt0 を排除（--no-std-crt0）し、スタックポインタを MSX システム変数安全域（$F380 等）に設定。関数呼び出しには引数をレジスタ渡しする __sdcccall(1) を指定することで、アセンブラに匹敵する超軽量・高効率なマシン語を生成します。 "SDCC development on MSX relies on a freestanding C subset without hosted runtime dependencies. By overriding standard CRT routines with a bespoke ROM header and enforcing __sdcccall(1) register passing, C99 routines compile into tight machine code rivaling hand-written assembly."
01 / Invocation

1. コンパイラ・リンカ起動規約 (Compiler Invocations)

Command Line Flags · Code & Data Segment Placement

32 KiB フラット ROM カートリッジ（0x4000–0xBFFF）を生成するための標準ビルドコマンドです。
"Standard compilation and linking commands configuring code origin at 0x4020, cartridge header at 0x4000, and initialized RAM at 0xC000." 
# 1. 独自 crt0 のアセンブル (Pasmo または sdasz80)
sdasz80 -o crt0_msx.rel crt0_msx.s

# 2. C99 ソースのコンパイル (最適化 & レジスタ呼出規約)
sdcc -mz80 -c --std-c99 --opt-code-size      --fomit-frame-pointer      main.c -o main.rel

# 3. リンク (ROM ヘッダ 0x4000, コード 0x4020, データ RAM 0xC000)
sdcc -mz80 --no-std-crt0      --code-loc 0x4020      --data-loc 0xC000      -Wl-b_HEADER=0x4000      crt0_msx.rel main.rel -o game.ihx

# 4. Intel HEX から生バイナリ ROM へ変換
hex2bin -e rom -l 0x8000 game.ihx
コンパイル引数 (Flag) 機能仕様 (Function) 技術的効果 (Technical Impact)
-mz80 Zilog Z80 ターゲット指定 Z80 命令セット（IX/IY レジスタ、EXX、LDIR 等）をフル活用
--no-std-crt0 標準 C ランタイム初期化の除外 余計なホスト初期化を排除し、独自の MSX ROM ヘッダをリンク可能にする
--opt-code-size コードサイズ最優先最適化 ループ展開を抑止し、インライン化よりもサブルーチン化を優先
--fomit-frame-pointer フレームポインタ (IX) の省略 関数呼び出し時の push ix / ld ix,sp オーバヘッドを排除
--code-loc 0x4020 実行コード開始アドレス ROM ヘッダ領域（0x4000–0x401F）の直後に C 関数を配置
--data-loc 0xC000 変数領域開始アドレス メイン RAM 領域（ページ 3: 0xC000）に変数を割り当て
02 / ABI

2. レジスタ呼出規約 (__sdcccall(1) ABI)

Parameter Passing via Registers · Stack Minimization

SDCC 4.2 以降で標準となった __sdcccall(1) は、関数の引数をスタックではなく Z80 のレジスタ群へ直接割り振ります。
"The __sdcccall(1) application binary interface passes up to three function arguments through HL, DE, and BC registers, eliminating stack frame manipulation."
引数位置 (Parameter) 8-bit 引数 (char, uint8_t) 16-bit 引数 (int, uint16_t, pointer) 32-bit 引数 (long, uint32_t)
第 1 引数 L レジスタ HL レジスタペア HL (下位) + DE (上位)
第 2 引数 E レジスタ DE レジスタペア スタック渡し
第 3 引数 C レジスタ BC レジスタペア スタック渡し
戻り値 (Return) L レジスタ HL レジスタペア HL (下位) + DE (上位)
03 / crt0

3. MSX カートリッジ crt0 原典 (crt0_msx.s)

ROM Header · Segment Zeroing · Main Execution

実機およびエミュレータが起動時に認識する 16 バイトのカートリッジヘッダと初期化アセンブラです。
"Minimalist crt0 routine embedding the mandatory 0x4142 cartridge signature, initializing stack pointer, copying initialized data from ROM to RAM, and entering main()." 
;; ══════════════════════════════════════════════════════════════════════
;; crt0_msx.s — Minimal MSX Cartridge CRT for SDCC
;; ══════════════════════════════════════════════════════════════════════
        .area   _HEADER (ABS)
        .org    0x4000

        .db     0x41, 0x42      ; "AB" マーカー (MSX カートリッジ識別子)
        .dw     init_entry      ; 実行開始アドレス
        .dw     0x0000          ; CALL 文フック (未使用)
        .dw     0x0000          ; デバイス拡張 (未使用)
        .dw     0x0000          ; BASIC テキスト (未使用)
        .dw     0x0000, 0x0000  ; 予約領域

        .area   _CODE
init_entry:
        di
        ld      sp, #0xF380     ; スタックポインタをワークエリア直下に初期化

        ; 初期化済みデータセクション (_INITIALIZED) を ROM から RAM へ転送
        ld      hl, #s__INITIALIZER
        ld      de, #s__INITIALIZED
        ld      bc, #l__INITIALIZED
        ld      a, b
        or      c
        jr      z, skip_copy
        ldir
skip_copy:

        ; 未初期化データセクション (_DATA) のゼロクリア
        ld      hl, #s__DATA
        ld      de, #s__DATA + 1
        ld      bc, #l__DATA - 1
        ld      (hl), #0
        ldir

        ei
        call    _main           ; C 言語の main() 関数へ突入

halt_loop:
        halt
        jr      halt_loop
04 / VDP

4. インラインアセンブラと高速 VDP 制御

Direct Port Access · Zero Overhead

V9938 / TMS9918A のレジスタを最速で直接叩くための C99 インラインマクロです。
"C inline assembly macros interfacing with hardware ports 0x98 and 0x99, avoiding function call overhead." 
// VDP レジスタ書き込みマクロ (Port 0x99)
static inline void vdp_set_reg(uint8_t reg, uint8_t val) {
    __asm
        ld  a, l        ; __sdcccall(1) により reg は L
        ld  c, #0x99
        out (c), a      ; 値を出力
        ld  a, e        ; val は E
        or  #0x80       ; レジスタ書き込みフラグ (Bit 7 = 1)
        out (c), a      ; レジスタ番号を出力
    __endasm;
}

// VRAM 書き込みアドレス設定 (14-bit VRAM Address)
static inline void vdp_set_write_addr(uint16_t addr) {
    __asm
        ld  a, l        ; addr 下位バイト (L)
        out (#0x99), a
        ld  a, h        ; addr 上位バイト (H)
        and #0x3F       ; 14-bit マスク
        or  #0x40       ; VRAM 書込フラグ (Bit 6 = 1)
        out (#0x99), a
    __endasm;
}
