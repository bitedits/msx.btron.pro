Pasmo (Assembler)

確定的固定アドレス Z80 クロスアセンブラ Pasmo による MSX カートリッジ、MSX-DOS、および BLOAD 生成仕様。 "Technical guide for Pasmo, a portable multi-platform Z80 cross-assembler generating raw ROM images, MSX-DOS .COM files, and BLOAD binaries with symbol export."
← 開発目録へ戻る (Development Index)
Pasmo アセンブラの特長 — Pasmo はリンカを介さず、ソースコード内の ORG 指示語に基づいて直接単一バイナリを出力する固定アドレスアセンブラです。MSX 向けに特化した --msx オプションを備え、7 バイトの BLOAD ヘッダ（開始アドレス、終了アドレス、実行アドレス）を自動付与して出力可能。また、openMSX や blueMSX にロード可能なシンボルファイルを生成します。 "Pasmo is a self-contained fixed-address assembler emitting monolithic binaries directly from single-pass assembly sources. Its native --msx switch prepends the 7-byte MSX BLOAD header, while the symbol output flags produce map files loadable by openMSX and blueMSX debuggers."

コマンド引数 (Flag) 出力形式 (Format) 機能仕様と使用例 (Usage Example)

02 / Example

2. 実践的 MSX カートリッジコード例 (Cartridge Example)

Screen Mode Initialization · PSG Beep

Pasmo でアセンブル可能な、画面初期化と PSG ビープ音を鳴らす最小カートリッジコードです。
"Self-contained assembly example initializing screen mode, setting background palette, and emitting a test tone via the AY-3-8910 PSG." 
; ══════════════════════════════════════════════════════════════════════
; hello_msx.asm — Pasmo Minimal MSX Cartridge
; Build: pasmo --bin hello_msx.asm hello_msx.rom
; ══════════════════════════════════════════════════════════════════════
        org     4000h

        db      "AB"            ; MSX ROM Cartridge ID
        dw      start           ; Start Execution Vector
        dw      0               ; CALL statement
        dw      0               ; Device expansion
        dw      0               ; Basic text
        dw      0, 0            ; Reserved

start:
        di
        ld      sp, 0F380h      ; Set stack pointer

        ; Screen 1 に設定 (BIOS CALL)
        ld      a, 1
        call    005Fh           ; CHGMOD (Change Screen Mode BIOS vector)

        ; 背景色を Teal (#008080) に近いシアンに設定
        ld      a, 7            ; Color Cyan
        ld      (0F3E9h), a     ; BAKCLR system variable
        call    0062h           ; CHGCLR BIOS vector

        ; PSG チャンネル A でトーン出力 (440 Hz)
        ld      a, 0
        ld      e, 0FEh         ; Fine Tune
        call    write_psg
        ld      a, 1
        ld      e, 00h          ; Coarse Tune
        call    write_psg
        ld      a, 7
        ld      e, 0FEh         ; Mixer: Enable Tone on Channel A
        call    write_psg
        ld      a, 8
        ld      e, 0Fh          ; Volume: Maximum
        call    write_psg

loop:
        ei
        halt
        jr      loop

; PSG レジスタ書込ルーチン (A = Reg, E = Data)
write_psg:
        out     (0A0h), a       ; Latch Register
        ld      a, e
        out     (0A1h), a       ; Write Value
        ret

        ; 32KB カートリッジを満たすパディング
        ds      8000h - ($ - 4000h), 0FFh
