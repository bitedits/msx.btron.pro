8-bit BTRON (Systems)

MSX の Z80 バンク空間上に再構成された、超漢字・実身仮身ハイパーメディアモデルと確定性 µITRON ランタイム。 "Technical specification for the 8-bit BTRON runtime on MSX, implementing Real/Virtual body network records, 8-bit TAD segments, and cooperative event queues inside banked memory."
← 基本ソフト目録へ戻る (Systems Index)
BTRON と MSX の邂逅 — BTRON（Business TRON）は、坂村健氏が構想した人間中心の統一オペレーティングシステムであり、階層ファイルシステムに代わる実身（Real Object）と仮身（Virtual Object）のネットワーク構造（ハイパーメディア）を根幹に持ちます。8-bit BTRON は、ワークステーション向けの巨大な仕様を 64 KiB の MSX Z80 上に凝縮。16 KiB メモリマッパーをスワップ単位として用い、TAD（TRON Application Databus）テキストとウィンドウ枠を V9938/V9958 上へ直接描画します。B-System の B-MSX では、この実身仮身空間と完全に直結する C99 確定性コアを提供します。
"8-bit BTRON adapts the seminal TRON real/virtual body hypermedia paradigm to the 8-bit Z80 addressing plane. By leveraging 16 KiB memory mapper segments as storage blocks, it hosts TAD variable-length records and cooperative window primitives without requiring workstation-class MMUs. In B-System, the B-MSX core tightly integrates with this hypermedia model under strict C99 determinism."
01 / Record

1. BMSX 実身レコード構造 (BMSX Real-Body Record Layout)

Binary Offsets · Header Signatures · Link Chains · Mapper Blocks

MSX メモリマッパーセグメント上に永続化される BMSX 実身レコードのバイナリ構造です。
"Binary layout of the BMSX real-body record stored inside 16 KiB mapper pages, defining object ID, parent pointers, and TAD segments."
バイトオフセット (Offset) フィールド名 (Field) 型・サイズ (Type) 機能仕様と定義 (Functional Specification)
+0x00..+0x03 magic char[4] 固定シグネチャ "BMSX" (実身レコード識別子)
+0x04..+0x05 body_id uint16_t 一意の実身番号 (0x0001–0xFFFF)。0x0000 は無効・未使用レコード。
+0x06..+0x07 parent_id uint16_t 所属仮身（リンク元）の実身番号。ルートウィンドウ実身は 0x0000。
+0x08..+0x09 record_len uint16_t 後続する TAD セグメントデータの総バイト数 (ヘッダ 16 バイトを除く)。
+0x0A..+0x0B flags uint16_t 属性フラグ (Bit 0: 読取専用, Bit 1: 変更済ダーティ, Bit 2: 暗号化, Bit 3: フォルダ実身)。
+0x0C..+0x0F mtime uint32_t 最終更新日時 (UNIX エポック秒、または RTC リアルタイムクロック値)。
+0x10..+EOF tad_payload uint8_t[] 8-bit TAD 可変長セグメントストリーム (テキスト・仮身リンク・図形プリミティブ)。
02 / TAD

2. 8-bit TAD セグメント仕様 (8-bit TAD Segment Primitives)

Variable-Length Segments · Hypermedia Tags · V9938 Acceleration

BTRON のデータ交換標準である TAD（TRON Application Databus）の 8 ビットセグメント仕様です。
"Specification of 8-bit TAD primitives packing plain text, font changes, and virtual-body link tags into sequential streams."
セグメント ID 名称 (Segment Name) 構造・引数 (Arguments) 機能仕様とハードウェア動作 (Functional Specification)
0x01 テキスト (Text Run) len (uint8), chars[] TRON コード JIS 第1/第2水準漢字および ASCII 文字列。漢字ROM ポート経由で描画。
0x02 仮身タグ (Link Tag) target_body_id (uint16), icon_id (uint8), title_len (uint8), title[] 他の実身を開くためのアイコン（仮身）を文章中に埋め込み。ダブルクリックで該当実身を窓として開く。
0x03 図形描画 (Vector Primitive) cmd (uint8), x0 (int16), y0 (int16), x1 (int16), y1 (int16), color (uint8) V9938 ハードウェア描画エンジン（LINE / HMMV）への直接指示。矩形、線分、楕円の描画。
0x04 書体変更 (Font Face) font_id (uint8), size_pt (uint8) 明朝体、ゴシック体、英数フォントの指定、およびポイントサイズ切り替え。
0x05 ビットマップ面 (Bitmap Plane) width (uint16), height (uint16), bpp (uint8), data[] モノクロまたは 16 色ビットマップ画像データをインライン展開。
0x06 色属性 (Color Attribute) fg_color (uint8), bg_color (uint8) 後続するテキスト描画の描画色（前景色・背景色パレット番号）を変更。
0xFF 終端記号 (Stream End) なし TAD ペイロードの終了を示し、ストリームパーサの処理を完了。
03 / TRON Code & Kanji

3. TRON 多言語文字コードと漢字ROM制御 (TRON Code & Kanji ROM)

JIS X 0208 · Ports $D8–$DB · 16×16 Font Matrix Paging

BTRON の特徴である多言語文字処理体系と、MSX 実機の漢字ROM（JIS 第1・第2水準）ハードウェアインターフェース仕様です。
"Hardware register specification for Japanese Kanji ROM addressing (Ports $D8–$DB), streaming 16×16 glyph bitmaps directly into VRAM."
I/O ポート (Port) アクセス レジスタ機能 (Register Function) ハードウェア動作仕様 (Silicon Interface)
0xD8 書込専用 (Out) 第1水準漢字ROM アドレス下位 (A0–A7) JIS 区点コードから算出された 16×16 ドットグリフ（32バイト）の先頭アドレス下位を設定。
0xD9 書込専用 (Out) 第1水準漢字ROM アドレス上位 (A8–A16) 漢字ROM アドレス上位を設定。アドレス設定後、ポート 0xD9 からの連続読出が可能となる。
0xD9 読出専用 (In) 第1水準漢字ROM データ (32バイト順次読出) 1 バイト読み出すごとに内部アドレスカウンタが自動インクリメント。32 回連続リードで 1 文字分取得。
0xDA 書込専用 (Out) 第2水準漢字ROM アドレス下位 (A0–A7) JIS 第2水準漢字ROM の先頭アドレス下位ビットを設定。
0xDB 書込専用 (Out) 第2水準漢字ROM アドレス上位 (A8–A16) 第2水準漢字ROM のアドレス上位ビットを設定。
0xDB 読出専用 (In) 第2水準漢字ROM データ (32バイト順次読出) 第2水準漢字グリフデータの順次読み出し。
04 / Tasking

4. バンク空間における確定性 μITRON タスク機構 (μITRON Tasking in Banked RAM)

Deterministic Scheduling · Lightweight Event Queue · Cooperative Multitasking

Z80 のメモリマッパー空間上で協調動作する、μITRON 準拠の軽量リアルタイムイベント駆動機構です。
"Deterministic task scheduling primitives and message queue protocols operating within banked 16 KiB memory mapper slots."
システムコール (API) 引数 (Arguments) 機能仕様とスケジューリング動作 (Kernel Behavior)
b_cre_tsk tskid, pk_ctsk (優先度, エントリ番地, スタック) 新規タスクの生成。タスクコントロールブロック (TCB) を割り当て初期化。
b_sta_tsk tskid, stacd (起動コード) タスクを実行可能状態（READY）へ移行。スケジューラキューに登録。
b_snd_msg mbxid, pk_msg (メッセージポインタ) メールボックスへのメッセージ送信。キュー先頭の待機タスクを起床。
b_rcv_msg mbxid, pk_msg, tmout (タイムアウト) メールボックスからのメッセージ受信。空の場合は受信待ち（WAIT）状態へ遷移。
b_rot_rdq pri (優先度) 同一優先度タスクのラウンドロビン実行。協調型タスク切り替えの基本単位。
05 / Window Engine

5. ウィンドウ描画と V9938/V9958 統合 (Window Composition & Hardware Blitter)

3D Bevel Styling · Dirty Rectangles · Direct Framebuffer Composition

BTRON 標準の 3D ベベル境界、ウィンドウタイトルバー、およびマウスカーソル追従のハードウェア描画仕様です。
"Window manager rasterization using V9938 hardware command acceleration (HMMV/LMMV) for instant 3D bevels and scroll blitting."
描画要素 (GUI Element) 描画手法 / ハードウェアコマンド 技術仕様 (Technical Details)
ウィンドウ枠・ベベル V9938 LINE / HMMV コマンド 右上ハイライト（白）と左下シャドウ（濃灰）による 2px ベベル枠。CPU 介入なしに VDP が矩形描画。
タイトルバー V9938 HMMV 矩形塗りつぶし アクティブウィンドウは TRON 浅葱（#008080）、非アクティブ時は灰（#808080）をハードウェア高速転送。
スクロール更新 V9938 YMMM (VRAM 間垂直転送) 文章スクロール時に CPU による全再描画を行わず、VRAM 内部で矩形領域を一括スライド。
マウスカーソル ハードウェアスプライト (Plane 0) 矢印カーソルを VDP スプライト面 0 に配置。PSG ポート A/B 経由のパルスマウス入力を 60Hz 割込みで追従。
