8-bit BTRON (Systems)

MSX の Z80 バンク空間上に再構成された、超漢字・実身仮身ハイパーメディアモデルと確定性 µITRON ランタイム。 "Technical specification for the 8-bit BTRON runtime on MSX, implementing Real/Virtual body network records, 8-bit TAD segments, and cooperative event queues inside banked memory."
← 基本ソフト目録へ戻る (Systems Index)
BTRON と MSX の邂逅 — BTRON（Business TRON）は、坂村健氏が構想した人間中心の統一オペレーティングシステムであり、階層ファイルシステムに代わる実身（Real Object）と仮身（Virtual Object）のネットワーク構造（ハイパーメディア）を根幹に持ちます。8-bit BTRON は、ワークステーション向けの巨大な仕様を 64 KiB の MSX Z80 上に凝縮。16 KiB メモリマッパーをスワップ単位として用い、TAD（TRON Application Databus）テキストとウィンドウ枠を V9938/V9958 上へ直接描画します。 "8-bit BTRON adapts the seminal TRON real/virtual body hypermedia paradigm to the 8-bit Z80 addressing plane. By leveraging 16 KiB memory mapper segments as storage blocks, it hosts TAD variable-length records and cooperative window primitives without requiring workstation-class MMUs."
01 / Record

1. BMSX 実身レコード構造 (BMSX Real-Body Record)

Byte Offsets · Header Signatures · Link Chains

MSX メモリマッパーセグメント上に永続化される BMSX 実身レコードのバイナリ構造です。
"Binary layout of the BMSX real-body record stored inside 16 KiB mapper pages, defining object ID, parent pointers, and TAD segments."
バイトオフセット (Offset) フィールド名 (Field) 型・サイズ (Type) 機能仕様と定義 (Functional Specification)
+0x00..+0x03 magic char[4] 固定シグネチャ "BMSX" (実身レコード識別子)
+0x04..+0x05 body_id uint16_t 一意の実身番号 (0x0001–0xFFFF)
+0x06..+0x07 parent_id uint16_t 所属仮身（リンク元）の実身番号
+0x08..+0x09 record_len uint16_t 後続する TAD セグメントデータの総バイト数
+0x0A..+0x0B flags uint16_t 属性フラグ (Bit 0: 読取専用, Bit 1: 変更済, Bit 2: 暗号化)
+0x0C..+0x0F mtime uint32_t 最終更新日時 (エポック秒)
+0x10..+EOF tad_payload uint8_t[] 8-bit TAD 可変長セグメントストリーム (テキスト・図形)
02 / TAD

2. 8-bit TAD セグメント仕様 (TAD Segments)

Variable-Length Segments · TRON Multilingual Character Code

BTRON のデータ交換標準である TAD（TRON Application Databus）の 8 ビットセグメント仕様です。
"Specification of 8-bit TAD primitives packing plain text, font changes, and virtual-body link tags into sequential streams."
セグメント ID 名称 (Segment Name) 構造・引数 (Arguments) 機能仕様 (Functional Specification)
0x01 テキスト (Text Run) len (uint8), chars[] TRON コード JIS 第1/第2水準漢字および ASCII 文字列
0x02 仮身タグ (Link Tag) target_body_id (uint16) 他の実身を開くためのアイコン（仮身）を文章中に埋め込み
0x03 図形描画 (Vector Primitive) cmd (uint8), x0, y0, x1, y1 V9938 ハードウェア描画エンジンへの直接線分・矩形描画指示
0xFF 終端記号 (Stream End) なし TAD ペイロードの終了を示し、パーサを終了
