系統 (Systems)

標準 BIOS からディスクオペレーティングシステム、UNIX クローン、そして 8-bit BTRON に至る基本ソフトウェア体系。 "Comprehensive registry of operating systems and firmware powering the MSX platform, spanning standard MSX-BIOS vectors, MSX-DOS / Nextor, cleanroom C-BIOS, UZIX Unix V7, and the 8-bit BTRON hypermedia runtime."
基盤ソフトウェアの多様性 — MSX の 64 KiB バンク空間は、単一の静的 BIOS に制約されることはありませんでした。スロット多重化とメモリマッパーを駆使することにより、DOS、UNIX、そして坂村健氏が提唱した BTRON（超漢字・実身仮身ハイパーメディアモデル）の 8 ビット実装まで、高度なオペレーティングシステムが Z80 上で実稼働しました。 "The banked MSX addressing architecture liberated software developers from static firmware limitations. Through dynamic slot switching and memory mappers, the platform hosted CP/M-compatible disk operating systems, preemptive Unix kernels, and an 8-bit BTRON hypermedia engine."
