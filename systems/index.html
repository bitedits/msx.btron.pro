系統 (Systems)

標準 BIOS からディスクオペレーティングシステム、UNIX クローン、そして 8-bit BTRON に至る基本ソフトウェア体系。 "Comprehensive registry of operating systems and firmware powering the MSX platform, spanning standard MSX-BIOS vectors, MSX-DOS / Nextor, cleanroom C-BIOS, UZIX Unix V7, and the 8-bit BTRON hypermedia runtime."
基盤ソフトウェアの多様性とメモリ空間の解放 — MSX の 64 KiB バンク空間は、単一の静的 BIOS に制約されることはありませんでした。スロット多重化とメモリマッパー（16 KiB セグメント）を駆使することにより、CP/M 互換ディスク OS、プリエンプティブ UNIX、そして坂村健氏が提唱した BTRON（超漢字・実身仮身ハイパーメディアモデル）の 8 ビット実装まで、高度なオペレーティングシステムが Z80 上で実稼働しました。B-System の B-MSX では、これら全環境の相互運用性を C99 確定性コアとして忠実に再現しています。
"The banked MSX addressing architecture liberated software developers from static firmware limitations. Through dynamic slot switching and memory mappers, the platform hosted CP/M-compatible disk operating systems, preemptive Unix kernels, and an 8-bit BTRON hypermedia engine. Within B-System, the B-MSX C99 core accurately simulates these diverse OS environments under strict deterministic contracts."

"Cross-platform architectural comparison matrix evaluating memory requirements, kernel paradigm, and hardware compatibility."
基本システム・カーネル規約 (System & Kernel Architecture) 記憶階層・動作環境・B-MSX 連携 (Storage, Hardware & B-MSX Specification)
8-bit BTRON
協調型ハイパーメディア＋確定論的 μITRON タスクキュー
要件: 64 KiB RAM + 128 KiB メモリマッパー 		記録形式: BMSX 実身仮身ネットワーク / 8-bit TAD レコードストリーム
主要ハード: MSX2 (V9938), 漢字ROM (ポート 0xD8–0xDB), マウス
B-MSX 連携: GDEV ウィンドウ内直接描画、Geo3D パイプライン連携、確定同期
MSX-BIOS
ハードウェア抽象化ジャンプテーブル (HAL)
要件: 16 KiB ROM (Slot 0) + 16 KiB RAM 		記録形式: カセット CMT (1200/2400 baud), ROM カートリッジ (ヘッダ "AB")
主要ハード: MSX1 (TMS9918A), PSG (AY-3-8910)
B-MSX 連携: C-BIOS 相互置換、早送り (Fast-Forward 450フレーム)
MSX-DOS 2 & Nextor
CP/M 2.2 互換 BDOS + MS-DOS 階層ディレクトリ
要件: 64 KiB RAM + 64 KiB マッパー + Disk ROM 		記録形式: FAT12 (2DD 720KB), FAT16 (Nextor SD 最大 2GB / 65,524 クラスタ)
主要ハード: MSX2+, フロッピー / IDE / SD インターフェース
B-MSX 連携: WD2793 FDC エミュレーション、DOS コール互換レイヤ
C-BIOS
完全クリーンルーム互換 BIOS (BASIC 排除)
要件: 16 KiB / 32 KiB ROM 		記録形式: カートリッジ自動起動 (Auto-run)
主要ハード: MSX1 / MSX2 / MSX2+ / turboR (TMS9918A〜V9958)
B-MSX 連携: B-MSX 標準同梱、完全著作権フリー、瞬時ブート
UZIX (Unix V7)
プリエンプティブ Unix Version 7 カーネル
要件: 128 KiB〜512 KiB メモリマッパー 		記録形式: Unix V7 ファイルシステム (512B ブロック, Inode)
主要ハード: MSX2 (80桁テキスト), タイマー割込み (60Hz)
B-MSX 連携: マッパーポート 0xFC–0xFF 空間分離、多重タスク実行

3. メモリマッパーとスロット制御戦略 (Memory Paging Strategies)

PPI 8255 Port $A8 · Subslot Register $FFFF · Mapper I/O Ports $FC–$FF

各オペレーティングシステムが 64 KiB の Z80 アドレス空間（4 ページ）をどのように分割・活用しているかの設計比較です。
"Comparative analysis of Z80 address plane partitioning across the four 16 KiB architectural pages (Page 0 to Page 3)."
ページ・番地 (Page / Address) 各 OS における空間割当・制御仕様 (OS Partitioning & Paging Roles)
Page 0
0000H–3FFFH
16 KiB スロット/マッパー 		MSX-BIOS: BIOS ROM (ジャンプテーブル・初期化ベクタ $0000–$015B)
C-BIOS: クリーンルーム BIOS ROM (ジャンプ表・カートリッジ探索)
MSX-DOS 2: RAM (BDOS コール 0005H, TPA 0100H〜)
UZIX: プロセス ユーザ空間 (Text & Data, ポート 0xFC 切替)
8-bit BTRON: BTRON コアランタイム / TAD ストリームパーサ
Page 1
4000H–7FFFH
16 KiB スロット/マッパー 		MSX-BIOS: BASIC ROM / カートリッジ ROM (ヘッダ "AB" $4000)
C-BIOS: カートリッジ ROM (ヘッダ "AB" $4000) / MSX2 BIOS 拡張
MSX-DOS 2: RAM (TPA アプリケーション実行空間)
UZIX: プロセス ユーザ空間 (Heap & ユーザスタック, ポート 0xFD 切替)
8-bit BTRON: 実身レコードスワップ空間 (16KB マッパーセグメント)
Page 2
8000H–BFFFH
16 KiB スロット/マッパー 		MSX-BIOS: カートリッジ拡張空間 / システムワークエリア
C-BIOS: カートリッジ拡張空間 / Sub-ROM プリミティブ実行空間
MSX-DOS 2: RAM (TPA 拡張 / マッパー動的バンク)
UZIX: カーネル常駐コード (VFS キャッシュ, システムコールハンドラ)
8-bit BTRON: ウィンドウ管理 / V9938 ハードウェアレンダラ
Page 3
C000H–FFFFH
16 KiB スロット/マッパー 		MSX-BIOS: メイン RAM (システム変数 $F380–$FFFF, スタック)
C-BIOS: メイン RAM (システムワークエリア $F380–$FFFF, スタック)
MSX-DOS 2: RAM (MSX-DOS 2 カーネル作業域, ディスクバッファ)
UZIX: カーネルデータ (PCB 配列, Inode テーブル, 割込みスタック)
8-bit BTRON: μITRON イベントキュー, 仮身ポインタ, スタック
