MSX-BIOS (Systems)

ハードウェア抽象化の根幹を成すジャンプベクタ群、スロット間呼出機構、およびシステム作業領域辞書。 "Definitive technical specification of standard MSX-BIOS jump vectors ($0000–$015B), inter-slot execution mechanisms, and system variable work areas ($F380–$FFFF)."
← 基本ソフト目録へ戻る (Systems Index)
BIOS ジャンプ表の不変性 — MSX-BIOS は、全ハードウェアメーカーに対して同一のアドレス番地に同一のサブルーチンエントリ（`JP xxxx`）を配置することを義務付けました。これにより、カートリッジやアプリケーションは VDP の型番や基板配線の違いを意識することなく、標準ベクタ（`CALSLT` や `CHPUT`）をコールするだけで安全に画面表示や音響制御を行うことができます。 "The MSX-BIOS established a strict contract requiring identical three-byte JP instructions across fixed addresses ($0000–$015B). This invariant jump table allowed software to invoke screen changes, slot switching, and console I/O across all certified manufacturer models."
01 / Vectors

1. 主要ジャンプベクタ表 (Core Jump Vectors)

Slot Switching · Character I/O · VDP Subsystem

MSX-BIOS における代表的なエントリベクタのアドレスと引数仕様です。
"Fundamental entry points governing slot traversal, console character output, and VRAM memory block transfers."
アドレス (Address) ベクタ名 (Name) 引数・レジスタ (Parameters) 機能仕様 (Functional Specification)
$001C CALSLT IY: スロット番号, IX: 呼出アドレス 指定スロットのサブルーチンを呼び出し、完了後元のスロットへ安全復帰
$0024 ENASLT A: スロット番号, HL: アドレス空間 指定メモリページに指定スロットのメモリを恒久的に接続切替
$000C RDSLT A: スロット番号, HL: 読出アドレス 他スロットの 1 バイトを読み出し、A レジスタに格納
$0014 WRSLT A: スロット番号, HL: 書込アドレス, E: データ 他スロットの指定アドレスに 1 バイトを書き込み
$005C LDIRVM HL: RAM アドレス, DE: VRAM アドレス, BC: 長さ メイン RAM から VRAM への高速ブロック転送
$005F CHGMOD A: 画面モード番号 (0–8) VDP 画面モードの切り替え (Screen 0–8)
$00A2 CHPUT A: 文字コード 現在の画面カーソル位置へ 1 文字を表示
$009F CHGET 戻り値: A = 入力文字 キーボードバッファから 1 文字取得 (入力待機)
02 / Workarea

2. システム作業領域 (Work Area Variables)

System Memory $F380–$FFFF · VDP Register Mirrors

Z80 アドレス $F380–$FFFF に割り当てられた重要なシステム変数です。
"Dictionary of essential system variables stored in upper RAM, including VDP mirror bytes and keyboard buffers."
アドレス (Address) シンボル名 (Symbol) サイズ 機能仕様と役割 (Role & Definition)
$F3E0–$F3E7 RG0SAV–RG7SAV 8 バイト VDP レジスタ 0–7 の書き込み値退避ミラー（VDP レジスタは読出不可のため）
$F3E9 BAKCLR 1 バイト テキスト画面の背景色番号
$F3EA BDRCLR 1 バイト 画面周辺ボーダー色番号
$F380 LINL40 1 バイト SCREEN 0 の 1 行文字幅設定値
$FCC1 EXPTBL 4 バイト スロット 0–3 が拡張スロット（Subslot）か否かの識別テーブル
$FD9A H.KEYI 5 バイト タイマー割り込みフックルーチンジャンプ領域
