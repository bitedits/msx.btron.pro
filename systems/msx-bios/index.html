MSX-BIOS (Systems)

ハードウェア抽象化の根幹を成すジャンプベクタ群、スロット間呼出機構、システム作業領域辞書、および B-MSX C99 確定性実行規約。 "Definitive technical specification of standard MSX-BIOS jump vectors ($0000–$015B), inter-slot execution mechanisms, system variable work areas ($F380–$FFFF), and deterministic B-MSX C99 cleanroom kernel integration."
← 基本ソフト目録へ戻る (Systems Index)
BIOS ジャンプ表の絶対不変性とハードウェア抽象化 — MSX-BIOS は、全ハードウェアメーカーに対して同一のアドレス番地に同一のサブルーチンエントリ（JP xxxx）を配置することを義務付けました。これにより、カートリッジやアプリケーションは VDP の型番や基板配線の違いを意識することなく、標準ベクタ（CALSLT や CHPUT）をコールするだけで安全に画面表示や音響制御を行うことができます。B-System の B-MSX では、この仕様を忠実に反映し、クリーンルーム C-BIOS、Hitachi HD64180 / ASCII R800 / Z80 CPU パイプライン、漢字ROM、および 60Hz 確定同期駆動と完全統合しています。
"The MSX-BIOS established a strict contract requiring identical three-byte JP instructions across fixed addresses ($0000–$015B). This invariant jump table allowed software to invoke screen changes, slot switching, and console I/O across all certified manufacturer models. Within B-System, the B-MSX C99 core honors this exact abstraction layer, coupling C-BIOS dispatch, HD64180/R800/Z80 execution pipelines, Kanji ROM banking, and deterministic 60 Hz frame synchronization."
01 / Reset & RST

1. リセットおよび RST 再開ベクタ (Reset & RST Vectors)

Z80 Restart Instructions · Slot 0 Entry Points · Interrupt Vectors

Z80 の 1 バイト再開命令（RST 00H–38H）に呼応する、MSX-BIOS 最重要低レベルエントリ群です。
"Core single-byte restart primitives governing hardware cold/warm initialization, syntax parsing, inter-slot dispatch, and VBLANK interrupt handling."
番地 (Address) 命令 / ベクタ名 引数・レジスタ (Registers) 機能仕様とハードウェア動作 (Functional Specification)
$0000 RST 00H (CHKRAM) なし コールドリセット。メモリ整合性チェック、VDP初期化、スロット構成走査、ワークエリア構築後に BASIC またはカートリッジを起動。
$0008 RST 08H (SYNCHR) HL: テキストポインタ BASIC 構文解析。HL が指す文字と命令直後の 1 バイトを比較し、一致すれば HL を進めて復帰。不一致時は Syntax error。
$0010 RST 10H (RDSLT) A: スロット, HL: アドレス スロット間 1 バイト読み出し。指定スロットの HL 番地から 1 バイトを A に読み出し、スロット状態を復元。
$0018 RST 18H (CALSLT) IY: スロット, IX: 呼出先 スロット間サブルーチン呼出。スロットを動的切替して IX を実行し、終了後に呼出元スロット環境へ安全復帰。
$0020 RST 20H (DCOMPR) DE, HL: 比較値 16ビット符号なし数値比較。HL - DE を行い、Zero フラグ (一致) および Carry フラグ (HL < DE) をセット。
$0028 RST 28H (GETYPR) DAC / 記述子 BASIC 引数型評価。式の型（文字列、整数、単精度実数、倍精度実数）を判別し DAC レジスタへフラグを設定。
$0030 RST 30H (CALLF) 直後: スロット (1B) + 番地 (2B) インラインスロット呼出。呼出命令に続く 3 バイトのメタデータを解釈してスロット間コールを実行。
$0038 RST 38H (H.TIMI) 割込みコンテキスト 垂直同期マスク可能割込み（VDP VBLANK / IM1）。フレーム毎に JIFFY カウンタ更新、キーボード走査、H.TIMI フックを実行。
02 / Slots

2. スロット間メモリ切替機構 (Inter-Slot Memory Management)

PPI 8255 Port A · Subslots at $FFFF · Dynamic Bank Dispatch

MSX の最大 4 MiB 空間を管理する基本スロットおよび拡張サブスロットの制御ベクタです。
"Low-level memory paging vectors managing Primary Slot PPI 8255 ($A8) and Secondary Subslot registers ($FFFF inverted)."
番地 (Address) ベクタ名 (Identifier) 引数・レジスタ (Registers) 機能仕様とスロット切替プロトコル (Paging Logic)
$000C RDSLT A: スロット ID, HL: 番地 対象スロットの一時選択、(HL) からの 1 バイト読出、元スロットの復元。戻り値: A = 読出データ。
$0014 WRSLT A: スロット ID, HL: 番地, E: 値 対象スロットの一時選択、E の内容を (HL) へ書き込み、元スロットの復元。
$001C CALSLT IY: スロット ID, IX: 呼出番地 スタック上に復帰スロット番号を退避し、指定スロットへ切り替えて IX を実行。復帰時にスロットを再構成。
$0024 ENASLT A: スロット ID, HL: 対象ページ HL の上位 2 ビットが示すメモリページ（0〜3）に対し、指定スロットを恒久的に接続。スロットテーブル SLTTBL を更新。
$0030 CALLF リターンアドレス直後のパラメータ 呼び出し側コードブロック直後に埋め込まれたスロット ID (1 バイト) とアドレス (2 バイト) を参照してスロット間分岐。
スロット ID 表現規約 (Slot Identifier Format):
レジスタ A または IYH に渡すスロット ID は以下の 8 ビット構造を持ちます：
  • Bit 0–1 (PS): 基本スロット番号 (0〜3)。PPI 8255 ポート A ($A8) に対応。
  • Bit 2–3 (SS): 拡張サブスロット番号 (0〜3)。各基本スロット空間の $FFFF（反転値）に対応。
  • Bit 7 (EX): 拡張スロット指定フラグ (0 = 基本スロットのみ, 1 = 拡張サブスロット有効)。
03 / Display & VDP

3. 画面制御および VRAM 転送ベクタ (VDP & Graphics Subsystem)

TMS9918A / V9938 / V9958 · Block Transfers · Screen Mode Dispatch

VDP レジスタ書き込み、VRAM ダイレクトリード/ライト、および高速ブロック転送を抽象化するベクタ群です。
"Hardware abstraction vectors for video display processors, handling VRAM burst copying, screen transitions, and register mutations."
番地 (Address) ベクタ名 (Name) 引数・レジスタ (Parameters) 機能仕様とハードウェア動作 (Functional Specification)
$0041 DISSCR なし 画面ブランキング（表示無効化）。VDP レジスタ 1 の Bit 6 をリセットし、画面を非表示にして VRAM アクセスを高速化。
$0044 ENASCR なし 画面表示許可。VDP レジスタ 1 の Bit 6 をセットし、画面表示を再開。
$0047 WRTVDP B: データ, C: レジスタ番号 VDP コントロールレジスタ C にデータ B を書き込み、システムワークエリア RGnSAV を同期更新。
$004A RDVDP 戻り値: A = ステータス値 VDP ステータスレジスタ 0 の内容を読み出し、A に格納。
$004D SETRD HL: VRAM アドレス VDP の VRAM 読み出しポインタを HL に設定し、ポート $98（または $88）経由の連続読み出しを準備。
$0050 SETWRT HL: VRAM アドレス VDP の VRAM 書き込みポインタを HL に設定し、ポート $98（または $88）経由の連続書き込みを準備。
$0053 FILVRM HL: 開始番地, BC: 長さ, A: 書込値 VRAM 領域の高速フィル。開始番地 HL から BC バイト分を A の値で埋め尽くす。
$0056 LDIRMV HL: VRAM, DE: RAM, BC: 長さ ブロック転送（VRAM → RAM）。VRAM の HL からメイン RAM の DE へ BC バイトを一括転送。
$005C LDIRVM HL: RAM, DE: VRAM, BC: 長さ ブロック転送（RAM → VRAM）。メイン RAM の HL から VRAM の DE へ BC バイトを一括高速転送。
$005F CHGMOD A: 画面モード番号 (0〜8) 画面モード切り替え。モードに応じた VRAM 配置テーブル（名前・色・パターン・スプライト）および VDP レジスタを初期化。
$0062 CHGCLR FORGND, BAKCLR, BDRCLR 前景色、背景色、ボーダー色を一括適用。
$0069 CLRSPR A: 画面モード 全スプライトアトリビュートテーブルを初期化し、スプライトを非表示化。
$006C INITXT なし SCREEN 0 (40×24 テキストモード) の初期化。
$006F INIT32 なし SCREEN 1 (32×24 グラフィックテキストモード) の初期化。
$0072 INIGRP なし SCREEN 2 (256×192 高解像度グラフィックモード) の初期化。
$0075 INIMLT なし SCREEN 3 (64×48 マルチカラーモード) の初期化。
$007E SETGRP なし VDP をグラフィックモード（SCREEN 2）のアドレスマッピングに設定。
04 / Console I/O

4. コンソール入出力および文字制御 (Console & Peripheral I/O)

Keyboard Buffer · Screen Formatting · Line Input

標準文字出力、キーボードスキャン、ライン入力、およびファンクションキー制御ベクタです。
"Interactive I/O vectors for terminal emulation, ASCII printing, cyclic keyboard matrix sampling, and function key rendering."
番地 (Address) ベクタ名 (Name) 引数・戻り値 (Registers) 機能仕様 (Functional Specification)
$009C CHSNS 戻り値: Zero フラグ (0 = バッファ有) キーボードバッファの検査。キー入力が存在するか判定（ノンブロッキング）。
$009F CHGET 戻り値: A = 文字コード キーボードから 1 文字取得。バッファが空の場合はキーが押されるまで待機。
$00A2 CHPUT A: 出力文字コード 現在のカーソル位置へ 1 文字を表示し、カーソルを進める。制御文字（改行、CLS、ベル等）を適切に解釈。
$00A5 LPTOUT A: 送信データ プリンタポートへ 1 バイトを出力。ハンドシェイクがタイムアウトした場合は Carry フラグをセット。
$00A8 LPTSTT 戻り値: A (0xFF = 準備完了, 0 = ビジー) プリンタのステータス取得。
$00B1 INLIN 戻り値: HL = 入力バッファポインタ 1 行入力ルーチン。オートリピート、カーソル編集、BS キー処理を伴うフルラインエディタ。
$00B7 BREAKX 戻り値: Carry フラグ (1 = 押下) Ctrl+STOP キーが押されているかを検査。
$00C0 BEEP なし 標準ビープ音の発音。PSG を用いて短時間の矩形波警報音を出力。
$00C3 CLS なし 画面消去。テキスト画面全体を空白文字で埋め、カーソルを左上隅 (1, 1) に移動。
$00C6 POSIT H: 行番号 (Y), L: 桁番号 (X) テキストカーソルの物理座標を (L, H) に移動。
$00CF DSPFNK なし 画面最下行へのファンクションキーガイド（F1〜F5 / F6〜F10）の描画。
$00D2 TOTEXT なし グラフィックモードから直前のテキスト画面モードへの復帰。
$00D5 GTSTCK A: ポート (0=カーソル, 1=Joy1, 2=Joy2) ジョイスティックの方向取得。戻り値 A = 0 (停止) または 1〜8 (上・右上・右・右下・下・左下・左・左上)。
$00D8 GTTRIG A: トリガ (0=Space, 1=Joy1-A, 2=Joy2-A, ...) トリガボタン検査。戻り値 A = 0xFF (押下中) または 0x00 (非押下)。
05 / Sound

5. 音源サブシステムおよび PSG ベクタ (Sound & Synthesizers)

AY-3-8910 / YM2149 · YM2413 · Rigour vs Subtle Models

PSG 音源制御ベクタおよび B-System B-MSX が定義する音源合成コントラクトです。
"Hardware register manipulation for the AY-3-8910 programmable sound generator, coupled with B-MSX dual-synthesis contracts."
番地 (Address) ベクタ名 (Name) 引数・レジスタ (Parameters) 機能仕様とハードウェア動作 (Functional Specification)
$0090 GICINI なし PSG (AY-3-8910) のハードウェア初期化。全 16 レジスタをクリアし、音声出力を遮断。
$0093 WRTPSG A: PSG レジスタ番号 (0〜15), E: データ PSG レジスタへのデータ書き込み。音程、ノイズ、ミキサー、音量エンベロープを直接制御。
$0096 RDPSG A: レジスタ番号, 戻り値: A = データ PSG レジスタ値（ジョイスティックポート A/B 入力を含む）の読み出し。
$0099 STRTMS なし バックグラウンド PLAY 文音楽演奏ドライバの実行開始（タイマー割込み駆動）。
B-MSX 音響合成規約（Rigour と Subtle の分離設計）:
B-System MSX.html および MSX-SOUND.txt に定義された音源モデルは、確定論的エミュレーション（Rigour）と譜面生成（Subtle）を厳密に分離しています：
  • Rigour（再生中の物理チップ）: PSG 基本周波数 1,789,772 Hz（f = 1789772 / (16·TP)）。16段階対数減衰（0, 51, 57, 64, 71, 80, 90, 101, 113, 127, 143, 160, 180, 202, 227, 255 を左5ビットシフト、最大 8160）。エンベロープ 0x0B は最大保持、0x0F は無音保持。スピーカ直流遮断ハイパスフィルタは約 14 Hz。
  • Subtle（B-Sound 譜面用）: 44,100 Hz ステレオ S16、master_soft_clamp、パン 0。矩形波 PULSE、振幅 0.22、減衰 0.18 秒。
  • Konami SCC: f = 3579545 / (32·period)。周期 9 未満は無音。5 本の波形テーブルメモリ。
  • Yamaha YM2413 (OPLL): 128 段 × 0.375 dB。ビブラート 6.1 Hz（約 14 cent）、トレモロ 3.7 Hz（4.8 dB）、リズム +6 dB。
  • MSX turbo R PCM: 15,700 Hz。ポート 03H は次刻み出力、02H は即時（最大 48 段スルー）。0xFF 出力時は +8128。
06 / Work Area

6. システム作業領域辞書 (System Work Area Variables)

Upper Memory $F380–$FFFF · Hardware Save States · Interrupt Hooks

Z80 アドレス空間最上位 $F380–$FFFF に配置された、システムカーネル制御変数群の完全定義です。
"Definitive dictionary of system variables residing in upper RAM, mapping display tables, keyboard rings, and hardware interrupt hooks."
アドレス (Address) シンボル名 (Symbol) サイズ 機能仕様とハードウェア連携 (Functional Role & Layout)
$F380 LINL40 1 バイト SCREEN 0 (40桁テキストモード) における 1 行の最大文字幅 (デフォルト: 40)。
$F381 LINL32 1 バイト SCREEN 1 (32桁テキストモード) における 1 行の最大文字幅 (デフォルト: 29)。
$F384 TXTNAM 2 バイト SCREEN 0 パターンネームテーブルの VRAM ベースアドレス。
$F386 TXTCOL 2 バイト SCREEN 0 カラーテーブルの VRAM ベースアドレス。
$F388 TXTCGP 2 バイト SCREEN 0 パターングラフィックジェネレータテーブルの VRAM ベースアドレス。
$F38E T32NAM 2 バイト SCREEN 1 パターンネームテーブルの VRAM ベースアドレス。
$F394 GRPNAM 2 バイト SCREEN 2 パターンネームテーブルの VRAM ベースアドレス。
$F39A MLTNAM 2 バイト SCREEN 3 パターンネームテーブルの VRAM ベースアドレス。
$F3D4 CLIKSW 1 バイト キークリック音スイッチ (0 = 無効, 1 = 有効)。
$F3DC CSRY 1 バイト テキスト画面の現在のカーソル Y 座標 (1〜24)。
$F3DD CSRX 1 バイト テキスト画面の現在のカーソル X 座標 (1〜40 / 1〜32)。
$F3E0–$F3E7 RG0SAV–RG7SAV 8 バイト VDP レジスタ 0〜7 の書き込み値退避ミラー（VDP レジスタは書込専用のため、現在値をここに保持）。
$FFE7–$FFF6 RG8SAV–RG23SAV 16 バイト MSX2/V9938 拡張 VDP レジスタ 8〜23 の書き込み値退避ミラー。
$F3E9 BAKCLR 1 バイト 現在のテキスト画面背景色コード。
$F3EA BDRCLR 1 バイト 現在の画面外周ボーダー色コード。
$F3F8 GETPNT 2 バイト キーボードリングバッファの読出ポインタ番地。
$F3FA PUTPNT 2 バイト キーボードリングバッファの書込ポインタ番地。
$FBF0–$FC17 KEYBUF 40 バイト キーボード入力リングバッファ本体。
$FC9E JIFFY 2 バイト 垂直同期割込みごとにインクリメントされる 16 ビットフレームカウンタ (60Hz)。
$FCC1–$FCC4 EXPTBL 4 バイト 基本スロット 0〜3 が拡張スロット（サブスロット構成）を持つかを示すフラグ配列 (0x80 = 拡張)。
$FCC5–$FCD4 SLTTBL 16 バイト 各スロットおよびサブスロットの現在のメモリページ接続状態キャッシュ。
$FD9A H.KEYI 5 バイト キーボード割込みルーチン先頭フック領域（デフォルトは 5 バイトの RET / NOP）。
$FD9F H.TIMI 5 バイト タイマー割込み（VBLANK）フック領域。ユーザー定義 60Hz 処理の注入点。
07 / B-MSX C99 Integration

7. B-MSX C99 コアおよびクリーンルーム設計 (B-MSX & C-BIOS Architecture)

NASA/JPL Power of Ten · Fast-Forward · HD64180 / R800 Multi-CPU

B-System ワークベンチ空間に統合された C99 純実装エミュレーションエンジンにおける BIOS 実行アーキテクチャです。
"Deterministic C99 implementation details under NASA/JPL Power of Ten coding rules, integrating C-BIOS, fast-forwarding, and heterogeneous multi-CPU execution."
コンポーネント 対象規格 / 仕様 B-MSX C99 実装詳細 (Implementation Details)
C-BIOS 統合 オープンソース クリーンルームファームウェア 商用 MSX-BASIC ROM を必要とせず、カートリッジヘッダ（$4000 の "AB" シグネチャ、$4002 初期化ベクタ、$4004 実行ベクタ）を自動解析して即時実行。Hitachi HC-90/95 向け日本語 MSX2 C-BIOS (cbios_main_msx2_jp.rom) を標準搭載。
早送り (Fast-Forward) msx_app_fast_forward(int frames) 描画遅延を伴うことなく CPU 命令サイクルおよび VDP 内部カウンタのみを任意のフレーム数（450〜900 フレーム）高速進捗。BIOS ハードウェア診断およびメモリクリアをスキップし、瞬時にタイトル画面へ到達。
μITRON 確定同期 独立 μITRON タスク (msx_task) 組込みタスクスケジューラ（cre_tsk / sta_tsk）直結の 60Hz 確定同期駆動。ウィンドウメッセージキューをブロックすることなく、PSG リアルタイム音声合成と 60fps スプライト走査をジッターなしで遂行。
マルチ CPU コア Z80A / R800 / HD64180 Z80A（3.58 MHz）の全非公開命令・フラグ計算・IM1/IM2、ASCII R800（28.6 MHz）の 16 ビット乗算命令（MULUB, MULUW）、および Hitachi HD64180（6.144 MHz）の 8 ビット乗算（MLT）、内部 I/O レジスタ（IN0/OUT0）、非破壊論理積（TST/TSTIO）、スリープ（SLP）、プログラマブル・リロードタイマ（PRT ch0/1）を完全エミュレート。
漢字 ROM & FDD JIS X 0208 Level 1 / 2 · WD2793 I/O ポート $D8–$DB 経由の 16×16 ドット漢字 ROM バンキング。HC-95 FDD ではフロッピーディスクドライブ ROM (720KB) および WD2793/MB89311 ディスクコントローラをシミュレート。
ゼロコピー描画 VDP 256×212 → GDEV バッファ V9938/TMS9918A のラスタライズ出力を B-System ワークベンチの GDEV ウィンドウバッファへダイレクトスケーリング転送。
