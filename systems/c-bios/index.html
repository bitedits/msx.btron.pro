C-BIOS (Systems)

BouKiCHi 氏らによってゼロから開発された、自由なライセンスを持つ MSX 互換ファームウェアと B-MSX 瞬時起動規約。 "Comprehensive technical specification of C-BIOS, a 100% cleanroom open-source MSX BIOS enabling legal emulator bundling, direct cartridge execution, and instant fast-forwarding."
← 基本ソフト目録へ戻る (Systems Index)
クリーンルーム設計の意義と著作権フリーの解放 — 原典の MSX-BIOS はマイクロソフトおよび各ハードウェアメーカーの著作権下にあるため、オープンソースエミュレータに同梱して自由に再配布することが法的に困難でした。C-BIOS は、公式仕様書の関数シグネチャと挙動規則のみを参照して完全に新規書き起こされたクリーンルーム実装です。プロプライエタリな BASIC インタープリタを省き、カートリッジの自動認識と即時起動に特化。B-System の B-MSX では、この C-BIOS を標準ファームウェアとして採用し、合法的なエミュレーション配布と高速早送り（Fast-Forward）を実現しています。
"C-BIOS eliminates copyright barriers by providing a pristine, cleanroom replacement for proprietary MSX ROMs. Designed specifically for gaming and emulator distribution, it implements the official BIOS jump table while omitting the proprietary MSX-BASIC interpreter. Within B-System, B-MSX bundles C-BIOS as its default firmware, pairing it with fast-forward frame skips and heterogeneous CPU emulation."

1. ビルド変種とバイナリ構成 (Target Variants & Matrix)

MSX1 · MSX2 · MSX2+ · turbo R Builds · Regional Keyboards

世代および地域（日本、欧州、ブラジル）に応じた C-BIOS のバイナリ構成です。
"Target matrix detailing generation-specific ROM files, regional keyboard maps, and video initialization configurations."
ROM ファイル名 対象世代 地域・キーボード サイズ 特徴と搭載機能 (Functional Capabilities)
cbios_main_msx1_jp.rom MSX1 日本 (JIS) 16 KiB TMS9918A VDP 制御、PSG サウンド、JIS 配列キーボード、カートリッジ直接起動。
cbios_main_msx2_jp.rom MSX2 日本 (JIS) 32 KiB V9938 グラフィックコマンド、パレット設定、RTC サポート。Hitachi HC-90/95 標準採用品。
cbios_main_msx2+_jp.rom MSX2+ 日本 (JIS) 32 KiB V9958 自然画モード、横スムーズスクロール、MSX-MUSIC (YM2413) 初期化。
cbios_main_msxtr.rom MSX turbo R 共通 32 KiB ASCII R800 CPU 検出、PCM 8ビット音声出力サポート、高速バス調停。
cbios_sub.rom MSX2 / 2+ / TR 共通 16 KiB Sub-ROM (スロット 0-1)。V9938/V9958 向け追加グラフィックプリミティブベクタ群。
cbios_music.rom MSX-MUSIC 共通 16 KiB FM-PAC 互換 OPLL (YM2413) 演奏ドライバおよび BASIC 拡張ステートメント。
cbios_logo_msx2.rom ブートロゴ 共通 16 KiB 起動時のグラフィカル C-BIOS ロゴアニメーション（早送りによりスキップ可能）。
02 / Cartridge Dispatch

2. カートリッジ自動認識と起動プロトコル (Cartridge Boot Protocol)

Signature "AB" ($4000) · Vector Execution · Mapper Sniffing

BASIC インタープリタを介さず、ROM カセットを瞬時に解析・起動する C-BIOS 内部手順です。
"Algorithmic execution path for inspecting $4000 'AB' ROM headers and auto-detecting MegaROM banking topologies."
オフセット番地 (Offset) フィールド名 期待値 (Value) 動作仕様 (Execution Protocol)
$4000–$4001 ヘッダシグネチャ "AB" (0x41 0x42) ROM カートリッジ識別記号。存在しない場合はスロット走査を継続。
$4002–$4003 INIT ベクタ アドレス (16-bit) カートリッジ初期化サブルーチン。画面モード設定やワークエリア確保を行う。
$4004–$4005 EXEC ベクタ アドレス (16-bit) ゲームプログラム本編エントリ番地。JP (EXEC) により本編へ制御を遷移。
$4006–$4007 STATEMENT 拡張 アドレス (16-bit) BASIC コールステートメント拡張ルーチン（C-BIOS では通常スキップ）。
$4008–$4009 DEVICE 拡張 アドレス (16-bit) 拡張 I/O デバイスドライバエントリ。
03 / Jump Implementations

3. 純粋 Z80 アセンブラによる互換ベクタ実装 (Pure Z80 Implementations)

Zero-Bloat Assembly · Invariant Register Calling Conventions

C-BIOS が標準 MSX-BIOS 仕様を満たすためにアセンブラで実装している主要ルーチンです。
"High-performance Z80 assembly implementations of official BIOS jump vectors, ensuring binary compatibility with commercial titles."
エントリ番地 ベクタ識別子 C-BIOS における実装手法 (Implementation Logic)
$001C CALSLT スタック上に現在の PPI 8255 ポート A および $FFFF サブスロット状態を退避し、指定スロットのページを有効化して CALL (IX) を実行。復帰時にスロット状態を完全復元。
$0024 ENASLT 渡されたスロット番号に基づき、対象アドレスページのポート A または $FFFF レジスタを書き換え、システムテーブル SLTTBL を更新。
$005C LDIRVM ポート $99（または $89）に書き込みアドレスを設定した後、OTIR 命令を用いてメイン RAM から VDP ポート $98 へ高速バースト転送。
$005F CHGMOD レジスタ A に応じて VDP 初期化テーブルを選択。SCREEN 0〜8 のレジスタ 0〜7 / 8〜23 を一括書き込みし、RGnSAV を更新。
$00A2 CHPUT SCREEN 0/1/2 の各文字パターンテーブルを走査し、カーソル位置 (CSRX, CSRY) の VRAM ネームテーブルへ ASCII コードを書き込み。
04 / B-MSX Integration

4. B-System B-MSX への統合と高速早送り (B-MSX Integration & Fast-Forward)

NASA/JPL Power of Ten · Fast-Forward Skip · Zero Copyright Encumbrance

B-System の C99 コアにおいて、C-BIOS がどのように活用され、高速起動を実現しているかの仕様です。
"Integration details within B-System B-MSX, demonstrating fast-forward boot skips and unencumbered open-source redistribution."
機能特徴 (Feature) B-MSX C99 アーキテクチャでの動作 (Architecture Specification)
早送り (Fast-Forward) msx_app_fast_forward(450) により、C-BIOS の起動ロゴおよび初期化待機ループを 0 秒で通過。描画更新をバイパスして命令サイクルのみを進めるため、瞬時にタイトル画面へ到達。
著作権フリー配布 C-BIOS は GPL/BSD ライセンスであるため、B-System リポジトリおよび WebAssembly バイナリへ合法的に直接内蔵可能。外部 ROM ダンプ作業が一切不要。
HC-90/HC-95 互換 Hitachi HC-90 / HC-95 ワークステーションの実行時には、日本語 MSX2 C-BIOS (cbios_main_msx2_jp.rom) と JIS 第1/第2水準漢字ROM を自動結合してマッピング。
多機種自動切替 装填された ROM カートリッジの容量とヘッダ特性（XRacing=MSX1, Bad Apple=MSX2+, BULLRUSH=MSX2/TR）に基づき、B-MSX が適切な C-BIOS 変種を動的に配備。
