MSX-DOS (Systems)

CP/M 互換 BDOS 呼出規約と MS-DOS FAT ファイルシステムの完全統合、および現代の Nextor 拡張。 "Complete technical specification of MSX-DOS 1/2 and Nextor, detailing INT 21h system calls, FCB/handle file management, FAT12/FAT16 disk structures, and modern storage drivers."

Tim Paterson による架け橋 — MSX-DOS は、MS-DOS の原作者であるティム・パターソン氏らによって開発されました。8 ビット Z80 空間で CP/M 2.2 と完全なシステムコール互換性を保ちながら、ディスクフォーマットには PC/AT 互換機と直接交換可能な FAT12 を採用。さらに MSX-DOS 2 では階層ディレクトリとメモリマッパー環境変数が導入され、現代のオープンソース Nextor によって FAT16 大容量 SD カード運用へと進化しました。 "Engineered by MS-DOS author Tim Paterson, MSX-DOS bridged the 8-bit CP/M software ecosystem with the IBM PC FAT filesystem standard. Running out of address $0100 in transient program areas, it progressed from FAT12 floppy disks to MSX-DOS 2 directory trees and Albert Beevendorp's FAT16 Nextor kernel."

1. BDOS システムコール規約 (INT 21h API)

Entry Point $0005 · C Register Functions

MSX-DOS プログラムは、アドレス $0005 へ CALL することで BDOS 機能を呼び出します。
"Primary disk operating system routines invoked by loading function code into register C and calling address $0005."
機能番号 (C Reg) 機能名 (Function Name) 入力引数 (Input) 戻り値 (Output) 仕様概要 (Functional Specification)
0x02 Console Output E = 文字コード なし コンソール画面へ 1 文字出力
0x09 Output String DE = '$' 終端文字列 なし '$' で終わる文字列を画面に出力
0x0F Open File (FCB) DE = FCB ポインタ A = 0 (成功) / 0xFF (失敗) ファイルコントロールブロックによるファイルオープン
0x43 Open File Handle DE = パス文字列, A = モード B = ハンドル, A = エラー MSX-DOS 2: ハンドルによるファイルオープン
0x48 Read File Handle B = ハンドル, DE = バッファ, HL = 長さ HL = 読込バイト数 MSX-DOS 2: ハンドルからの指定バイト数読出
