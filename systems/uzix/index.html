UZIX (Systems)

8 ビット MSX 上で稼働する、プロセス仮想メモリとプリエンプティブマルチタスクを備えた本格 Unix V7 クローン。 "Complete technical specification of UZIX, a true Unix Seventh Edition clone running on Z80 MSX hardware utilizing memory mappers for per-process memory virtualization."
← 基本ソフト目録へ戻る (Systems Index)
Z80 上の真の UNIX — UZIX は、PC 向け Unix V7 の設計を MSX Z80 へ移植したオペレーティングシステムです。ハードウェア MMU を持たない Z80 において、MSX のメモリマッパー（16 KiB セグメント）をプロセス空間切り替え機構として活用。プロセスごとに独立した 32 KiB のユーザ空間を提供し、タイマー割り込みによるプリエンプティブスケジューリング、fork/exec、Unix パイプ、および標準シェル（sh）を実現しました。 "UZIX demonstrates the surprising sophistication of MSX hardware by deploying a preemptive Unix V7 kernel onto banked Z80 architecture. By multiplexing memory mapper segments to serve as virtual address spaces, it provides true process isolation, pipe IPC, and a standard Unix userland."

1. カーネルアーキテクチャ (Kernel Architecture)

Preemptive Scheduler · Process Memory Layout

UZIX カーネルのメモリ構成とプロセス空間の割り当て仕様です。
"Memory plane partitioning isolating the resident kernel from dynamic user process contexts using memory mapper ports."

0x0000–0x7FFF (Page 0–1) ユーザプロセス空間 (User Process Context) プロセス切り替え時にマッパーポート 0xFC/0xFD で物理 RAM を切り替え

0xC000–0xFFFF (Page 3) カーネルデータ、スタック、ハードウェア I/O 常駐固定セグメント (割込ハンドラとシステムワークエリア)
