T-BIOS & T-DOS (Systems)

B-System B-MSX 確定性エミュレータのために完全自作・設計された、クリーンルーム互換 BIOS ファームウェアおよびディスクオペレーティングシステム体系。 "Definitive technical specification of T-BIOS and T-DOS: cleanroom open-source firmware and disk operating system built for B-System B-MSX, encompassing 8 binary targets, 117 jump vectors ($0000–$0183), Sub-ROM V9938/58 graphics primitives, OPLL music synthesis, dual Z80/R800 execution, Page-0 RAM trampolines, virtual TC8566AF FDC driver, MSX-DOS 1/2 BDOS syscalls, and blueMSX INI configuration."

独立性と確定性を極めた次世代クリーンルーム・ファームウェア — T-BIOS（TRON BIOS）および T-DOS（TRON Disk Operating System）は、MSX プラットフォームの知的財産制約を完全に克服し、BTRON 3.20 ハイパーメディア環境との結合を可能にするためにゼロからアセンブラおよび C99 で再実装された独立ファームウェア体系です。原典 MSX-BIOS の 117 基本ベクタと互換性を保ちながら、MSX1 から turbo R（ASCII R800）および日立 HC-90/HC-95（HD64180）までの全世代を網羅。Grauw 規約準拠の Page-0 RAM 実行環境、MSX-DOS 1/2 デュアル BDOS コール、および TC8566AF 仮想フロッピードライバを内蔵し、あらゆる市販カートリッジおよびディスク資産の 100% 確定ブートを保証します。
"T-BIOS and T-DOS represent an unencumbered, high-performance cleanroom firmware suite engineered from first principles for B-System B-MSX. Maintaining 100% binary parity across all 117 standard BIOS jump vectors ($0000–$0183), the architecture spans MSX1, MSX2, MSX2+, MSX turbo R (ASCII R800 dual-CPU), and Hitachi HC-90/95 (HD64180 20-bit MMU). Incorporating Grauw-standard Page-0 RAM trampolines, MSX-DOS 1/2 dual BDOS system calls, and a TC8566AF virtual sector driver, T-BIOS delivers uncompromising compatibility with zero proprietary ROM dependencies."

Zero-Copyright Encumbrance · Dual-BIOS Dynamic Switching · Deterministic Boot Path

ソニー公式技術資料（HB-F900/G900AP ファームウェア規約）に準拠した、T-BIOS の全 117 ジャンプベクタの完全定義です。

番地 (Address) ベクタ名 入力引数 (Registers In) 出力結果 (Registers Out) 破壊レジスタ 機能仕様とハードウェア動作 (Functional Specification)
$0000 CHKRAM なし なし 全レジスタ コールドリセット。RAM容量検査、スタックポインタ SP=$F380 設定、ワークエリア初期化、スロット走査。
$0008 SYNCHR HL: 文字列ポインタ HL: 次文字ポインタ AF 構文解析。HL の指す文字が呼出直後のバイトと一致すれば HL をインクリメント。不一致時は Syntax error。
$000C RDSLT A: スロットID, HL: アドレス A: 読み出しデータ F, C, DE スロット間 1 バイト読み出し。対象スロットを一時選択して (HL) を取得し、元のスロット状態を復元。
$0010 RST 10H A: スロットID, HL: アドレス A: 読み出しデータ F, C, DE RDSLT への 1 バイト再開命令エントリ。
$0014 WRSLT A: スロットID, HL: 番地, E: 値 なし AF, BC, D スロット間 1 バイト書き込み。対象スロットの (HL) へ E を書き込み、元のスロット状態を復元。
$0018 RST 18H IY: スロットID, IX: 呼出先 ルーチン依存 ルーチン依存 CALSLT への 1 バイト再開命令エントリ。
$001C CALSLT IY: スロットID, IX: 呼出先 ルーチン依存 ルーチン依存 スロット間サブルーチン呼出。スロット状態をスタックに退避し、指定スロットを有効化して CALL (IX) を実行。
$0020 DCOMPR HL, DE フラグ Z (一致), C (HL < DE) AF 16ビット比較サブルーチン。HL - DE の結果に基づきフラグを設定。
$0024 ENASLT A: スロットID, HL: 対象ページ なし 全レジスタ スロット有効化。HL の指すページ（0〜3）にスロット A を常時接続し、SLTTBL を更新。
$0028 GETYPR A: 型コード フラグ Z, S AF 変数データ型取得。文字・整数・単精度・倍精度浮動小数点の種別を判別。
$0030 CALLF 命令直後にスロットID・番地 ルーチン依存 ルーチン依存 インラインスロット間呼出。呼出命令の直後に配置されたスロットID（1バイト）と番地（2バイト）を読み取り実行。
$0038 KEYINT なし なし なし 垂直同期割込み (VBLANK / IM 1)。JIFFY インクリメント、キーボード走査、音楽ドライバ更新、フック H_TIMI 実行。
$0041 DISSCR なし なし AF, BC 画面表示禁止。VDP R#1 の BL ビットをクリアして画面をブランク状態にする。
$0044 ENASCR なし なし AF, BC 画面表示許可。VDP R#1 の BL ビットをセットして画面描画を再開する。
$0047 WRTVDP B: 書込値, C: レジスタ番号 なし AF, BC VDP レジスタ単一書き込み。ポート $99 を通じてレジスタ $C へ値 $B を書き込み、RGnSAV を更新。
$004A RDVDP なし A: 読出値 AF VDP 状態レジスタ S#0 読み出し（VBLANKフラグ判定）。
$004D VDPSTA A: 状態レジスタ番号 (0〜9) A: 読出値 F V9938/58 任意状態レジスタ読み出し。VDP R#15 に $A を書き込み、ポート $99 から状態を取得。
$0050 SETWRT HL: VRAM アドレス なし AF VRAM 書き込みアドレス設定。ポート $99 へアドレスを送信し、次回からポート $98 への連続出力で書き込み可能にする。
$0053 SETRD HL: VRAM アドレス なし AF VRAM 読み出しアドレス設定。ポート $99 へアドレスを送信し、ポート $98 から連続読み出しを可能にする。
$0056 FILVRM HL: 開始番地, BC: 長さ, A: 充填値 なし AF, BC VRAM メモリブロック充填。指定された $BC バイトの VRAM 領域を値 $A で塗りつぶす。
$0059 LDIRVM DE: VRAM開始番地, HL: RAM開始番地, BC: 長さ なし 全レジスタ RAM から VRAM への高速ブロック転送。OTIR 命令によるバースト転送を実施。
$005C LDIRMV DE: RAM開始番地, HL: VRAM開始番地, BC: 長さ なし 全レジスタ VRAM から RAM への高速ブロック転送。INIR 命令によるバースト転送を実施。
$005F CHGMOD A: 画面モード (0〜12) なし 全レジスタ 画面モード切り替え。Screen 0〜12 の VDP 各レジスタ・パレットを一括設定し、ネームテーブルを初期化。
$0062 CHGCLR (FORCLR), (BAKCLR), (BDRCLR) なし AF, BC 文字色・背景色・ボーダー色更新。VDP R#7 へ (FORCLR << 4) | BAKCLR を出力。
$0065 CLRSPR A: 画面モード なし 全レジスタ スプライト全消去。スプライト属性テーブル（$1B00等）の Y 座標を $D0 で充填し非表示化。
$006C INITXT なし なし 全レジスタ SCREEN 0 (40×24 テキストモード) 初期化。
$006F INIT32 なし なし 全レジスタ SCREEN 1 (32×24 テキストモード) 初期化。
$0072 INIGRP なし なし 全レジスタ SCREEN 2 (256×192 グラフィックモード) 初期化。
$0075 INIMLT なし なし 全レジスタ SCREEN 3 (マルチカラーモード) 初期化。
$0090 GICINI なし なし 全レジスタ PSG (AY-3-8910) 音源初期化。全 16 レジスタをクリアし消音。
$0093 WRTPSG A: レジスタ番号, E: 書込値 なし AF PSG レジスタ書き込み。ポート $A0 へレジスタ番号、$A1 へデータを出力。
$0096 RDPSG A: レジスタ番号 A: 読出値 AF PSG レジスタ読み出し。ポート $A0 へ番号を出力し、ポート $A2 から値を取得。
$0099 STRTMS なし なし 全レジスタ BGM / 効果音バックグラウンド再生開始。
$009C CHSNS なし フラグ Z (文字なし), NZ (文字あり) AF キーボードバッファ状態確認。入力文字の有無を非破壊で確認。
$009F CHGET なし A: 入力文字 ASCII コード AF キーボード 1 文字入力待ち。バッファから 1 文字取り出し、空の場合はキー押下まで待機。
$00A2 CHPUT A: 出力文字コード なし なし 画面 1 文字出力。エスケープシーケンス、改行コード処理、VRAM ネームテーブル書き込みを実施。
$00C6 BEEP なし なし 全レジスタ 警告ビープ音出力。PPI 8255 ポート C ビット 7 をトグル駆動。
$00C9 CLS なし なし 全レジスタ 画面消去。カーソルを左上隅 (1, 1) に戻し、ネームテーブルを空白コードで充填。

$00D9 GTTRIG A: トリガ番号 (0:Space, 1:Port 1-A, 2:Port 2-A, 3:Port 1-B, 4:Port 2-B) A: 押下状態 ($FF:押下, $00:未押下) AF ジョイスティック / スペースキー トリガボタン状態取得。

$013B WSLREG A: 基本スロット値 なし なし 基本スロット選択レジスタ (PPI ポート $A8) に A を書き込み。
$0141 SNSMAT A: マトリクス行番号 (0〜10) A: 列ピン状態 ($00〜$FF) AF, C キーボードマトリクス直接読み出し。指定行のピン状態（8キー）をビット単位で返却。
$0156 KILBUF なし なし なし キーボードバッファ消去。未処理の入力文字を破棄しポインタを初期化。
