c0man

パックマンのアーケード論理を忠実に再現したクリーンルーム実装。4 体のゴーストそれぞれに異なる AI 状態機械（追跡、待ち伏せ、気まぐれ、逃走）を与え、ドット単位のスムーズ移動を実現。 "Pristine cleanroom pac-maze implementation faithfully reproducing original arcade AI behavior. Models four distinct ghost state machines (chase, scatter, ambush, frightened) with sub-tile collision detection."

c0man (c0man) ソフトウェア工学要約 — 本タイトルは MSX1 向けに開発された 16 KiB 容量のカートリッジです。マッパーには 16 KiB Flat ROM を採用し、描画モードには Screen 2 (256×192)、音響には PSG (AY-3-8910) を駆使してハードウェア限界性能を追求しています。 "Technical profile for c0man. Engineered on MSX1 with 16 KiB storage using 16 KiB Flat ROM, rendering in Screen 2 (256×192) and voiced by PSG (AY-3-8910)."
