ネオン・レヴナント

B-System が誇るリアルタイム 3 次元幾何学エンジン『Geo3D』の真価を体現する 3D ベクタータイトル。Z80 の 16 ビット固定小数点演算による同次座標変換と、V9938 による高速ポリゴン描画を融合。 "Groundbreaking real-time 3D vector action game powered by the Geo3D pipeline within B-System. Employs 16-bit fixed-point arithmetic on the Z80 for 3D matrix transformations, coupled with V9938 hardware line rasterization."

ネオン・レヴナント (Neon Ravenant) ソフトウェア工学要約 — 本タイトルは MSX2 向けに開発された 256 KiB 容量のカートリッジです。マッパーには 256 KiB MegaROM を採用し、描画モードには Screen 5 (256×212 / 16色 パレット)、音響には PSG + YM2413 (MSX-MUSIC) を駆使してハードウェア限界性能を追求しています。 "Technical profile for Neon Ravenant. Engineered on MSX2 with 256 KiB storage using 256 KiB MegaROM, rendering in Screen 5 (256×212 / 16色 パレット) and voiced by PSG + YM2413 (MSX-MUSIC)."
