ブルラッシュ

ASCII 8K バンク切り替えマッパーを採用した高速アクションゲーム。V9938 のハードウェア高速転送（HMMV / LDIRVM）を駆使し、滑らかなスクロールとスプライトアニメーションを実現。C-BIOS 上でも軽快に動作。 "Fast-paced action title utilizing an ASCII 8K MegaROM bankswitching mapper. Leverages V9938 hardware blitter commands (HMMV/LDIRVM) for fluid 60 Hz frame animation and sprite multiplexing under C-BIOS execution."
← 遊戯目録へ戻る (Games Index)
ブルラッシュ (Bullrush) ソフトウェア工学要約 — 本タイトルは MSX2 / turboR 向けに開発された 128 KiB 容量のカートリッジです。マッパーには MegaROM (ASCII 8K Mapper) を採用し、描画モードには Screen 5 (256×212 / 16色 パレット)、音響には PSG (AY-3-8910) を駆使してハードウェア限界性能を追求しています。 "Technical profile for Bullrush. Engineered on MSX2 / turboR with 128 KiB storage using MegaROM (ASCII 8K Mapper), rendering in Screen 5 (256×212 / 16色 パレット) and voiced by PSG (AY-3-8910)."
