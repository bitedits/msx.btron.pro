ヤジアー

MSX1 の極限色彩美を追求したアーケードライクアクション。8×1 ドット内の 2 色制限（アトリビュートクラッシュ）を設計段階で巧みに排し、洗練されたタイトルカードと軽快な PSG メロディを響かせる。 "Exemplary MSX1 arcade action game engineered to showcase flawless graphics without attribute clash. Carefully aligns sprite and background color boundaries within 8x1 pixel character cells."

ヤジアー (Yazzier) ソフトウェア工学要約 — 本タイトルは MSX1 向けに開発された 16 KiB 容量のカートリッジです。マッパーには 16 KiB Flat ROM を採用し、描画モードには Screen 2 (256×192)、音響には PSG (AY-3-8910) を駆使してハードウェア限界性能を追求しています。 "Technical profile for Yazzier. Engineered on MSX1 with 16 KiB storage using 16 KiB Flat ROM, rendering in Screen 2 (256×192) and voiced by PSG (AY-3-8910)."
