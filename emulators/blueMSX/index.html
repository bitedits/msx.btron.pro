1. BiFi デバッグフック仕様 (BiFi Debug Hooks)

Assembler Idioms · Breakpoint & Trace Strings

Z80 アセンブラソースに直接埋め込むことで機能する、blueMSX 特有のデバッグ命令です。
"Assembly-level debug idioms recognized by blueMSX trace engine without requiring external symbol managers."
命令列 (Opcode Sequence) 機能仕様 (Function) 使用例・技術的詳細 (Technical Details)
ld b, b (0x40) ソフトウェアブレークポイント CPU がこの命令を実行すると、エミュレータが即時一時停止しデバッガを表示
ld d, d (0x52) デバッグトレース文字列出力 直後に配置された長さプレフィックス付き文字列をログウィンドウに出力 
; blueMSX デバッグフックの実装例
DEBUG_BREAK  macro
             ld b, b
             endm

DEBUG_PRINT  macro str
             ld d, d
             jr $+3 + len(str)
             db len(str), str
             endm
