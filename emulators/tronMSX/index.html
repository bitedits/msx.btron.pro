tronMSX (Emulators)

B-System に組み込まれた、確定性実行・ゼロコピー描画・44.1 kHz PCM 合成を備えた純 C99 MSX2+ コア。 "Technical specification of tronMSX, the embedded cleanroom C99 MSX2+ core within B-System. Built under strict NASA/JPL rules with zero dynamic allocation and deterministic frame execution."
← 摸擬目録へ戻る (Emulators Index)
確定性とクリーンルームの結晶 — tronMSX は、BTRON 3.20（B-System）のウィンドウ空間上で直接動作する MSX2+ エミュレーションコアです。NASA/JPL「Power of Ten」規則に厳格に従い、ブート後の動的ヒープ確保（malloc）を完全に禁止し、全ループを有界（Bounded）に抑え、静的メモリ空間のみで稼働します。描画フレームバッファは BTRON ウィンドウマネージャのプレーンへゼロコピーで転送され、音響は VirtIO-Sound / SDL2 へ 44.1 kHz 16-bit PCM として送出されます。 "tronMSX is an uncompromising cleanroom C99 MSX2+ engine embedded inside B-System. Adhering strictly to NASA/JPL Power of Ten rules, it forbids post-boot heap allocations and enforces bounded execution times. Frames are rendered directly into BTRON window planes without intermediate blitting."
